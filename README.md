# Fitness is me

A weightlifting tracker: log sets (with partial reps), see which muscle
groups you've hit today/this week on a body heat map, track a calendar of
sessions, get simple progression recommendations, and tag sessions with
menstrual cycle phase so strength dips get context instead of getting
misread as regression. Running/cardio is a placeholder tab for later.

Runs as a static site with Firebase (Firestore + Auth) as the backend, so
it works identically on desktop and phone once deployed.
